# my-tool

毎日のくり返し作業をワンクリックで自動化するツール「my-tool」のプロジェクトです。

現在は、ツールを紹介するランディングページを公開しています。

## ファイル構成

```
.
├── index.html   # ランディングページ本体
├── style.css    # ページのスタイル
└── README.md
```

## ランディングページの内容

- **ヘッダー**：ロゴとメニュー（スクロールしても上に固定）
- **メイン部分**：キャッチコピーと、はじめるためのボタン
- **特長**：「すぐに使える」「くり返しを自動化」「安心の設計」の3つ
- **使い方**：ダウンロード → 作業を登録 → あとはおまかせ の3ステップ
- **GitHub への誘導**とフッター

スマホの画面幅にも対応しています。

## 表示のしかた

外部ライブラリやビルドは不要です。`index.html` をブラウザで開くだけで表示できます。

```bash
open index.html   # macOS の場合
```

## 補足

ページ内の文章は仮の内容です。ツールの実際の機能に合わせて書き換えてください。
